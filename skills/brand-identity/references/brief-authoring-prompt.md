# Brand Brief Authoring Prompt

Use this prompt to build a decision-ready brief from a brand conversation. Read `identity-questionnaire.md`, `personality-archetypes.md`, and `color-psychology.md` first. If references are requested, use `../../shared-references/visual-analysis-workflow.md`.

“Create a brand brief for [brand/project] using only the user's statements and verified source material. First extract all supplied facts. Ask a concise question for any missing decision that would change the identity, such as exact name/script, offer, audience, market, customer promise/proof, personality, required touchpoints, or fixed constraints. Do not invent facts, claims, product variants, language/dialect, color values, or geography.

Summarize the audience's needs and the brand's offer. Define one clear positioning opportunity and list any evidence or open question. If visual research was requested, compare distinct public case studies, record direct links and project status, and describe transferable methods plus elements not to copy. Do not derive the client's colors or logo from a reference.

Offer a small number of visual routes, each tied to the brief: personality, shape/letterform behavior, palette direction with candidate exact hex codes, typography/language direction, image behavior, touchpoints, and risks. Label all values as proposed until the user approves them. Check color contrast for intended text/background use before recommending a combination.

Return a compact brief with status labels: LOCKED, PROPOSED, or OPEN. Include exact approved hex codes only when supplied or confirmed. Include script/language, market, audience, offer, promise/proof, differentiation, personality, type, imagery, channels, production/accessibility constraints, decisions, and source links. End with the specific decision needed before the logo stage. Do not generate a logo prompt until the user confirms the brief.”

## Compact brief output

| Field | Value | Status/source |
|---|---|---|
| Name and scripts | [exact spelling] | [status/source] |
| Offer/category | [what it does] | [status/source] |
| Market and audience | [country/region, audience, need] | [status/source] |
| Promise and proof | [supported outcome and evidence] | [status/source] |
| Differentiation | [specific opportunity] | [status/source] |
| Personality | [one or two traits plus plain-language read] | [status/source] |
| Palette | [exact HEX + roles] | [status/source] |
| Typography/language | [direction, scripts, reading direction] | [status/source] |
| Imagery/graphic language | [observable behavior] | [status/source] |
| Touchpoints | [real customer contexts] | [status/source] |
| Constraints/open questions | [items] | [status/source] |
| References | [direct URLs and “do not copy” notes] | [source/status] |
